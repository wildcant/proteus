# `core/`

`src/core/` is what is *known* — the vocabulary and the ports. `src/framework/` imports `core/`,
never the reverse; layers below (`modules/`, `workflows/`, `subscribers/`) import `core/` only. See
`src/core/README.md` for what sits here; ADR-0026 records the split and ADR-0027 the layer graph
that enforces it.
