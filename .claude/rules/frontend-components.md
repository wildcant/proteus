# Shared components

`src/components/` is the UI an app keeps outside any one feature, and `packages/ui` the primitives
both apps build on. Before building one — a form's UI, a data table, a modal opened as a route —
read `standards/rules/frontend/components/__docs__/README.md` and the document it routes you to.
